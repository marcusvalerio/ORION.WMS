# POP-ORN-39 · Rastrear lote e iniciar recall

**Onde:** Armazém › Rastreabilidade.

1. Escolha o produto e informe o lote. Clique em **Rastrear**.
2. **Para trás:** do acabado para os componentes e seus lotes (gravado na entrega à linha de produção).
3. **Para frente:** do componente para os acabados que o consumiram, os pedidos separados com esses lotes e os clientes.
4. **Iniciar recall** (supervisor ou administrador): informe o motivo e confirme.
   - todo o saldo disponível dos lotes afetados é **bloqueado** (movimento "bloqueio" com o código RCL);
   - o sistema grava a lista de clientes e pedidos a avisar;
   - o processo fica na auditoria.
